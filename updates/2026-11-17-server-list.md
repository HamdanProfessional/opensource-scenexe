**Open-Scenexe update: host your own server**

You can now run your own Open-Scenexe server and put it on a public server list.

- **Server list:** press Servers under the Play button to see the official server and every community server, with how many people are playing on each. Click Join to go there, or type any server address to join it directly.
- **Host your own:** download the game from GitHub and run `python start.py`. It sets everything up by itself, runs every gamemode, and updates itself when it restarts. Add your server name and address to `config.json` and it shows up on the list for everyone.
- **Hosting guide:** the README on GitHub explains every step, including opening your port, the settings in `config.json`, and the optional Discord bot.
