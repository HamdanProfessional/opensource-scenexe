**Open-Scenexe update: a smaller, endless Voidd**

Voidd has been rebuilt to run much lighter on the server.

- **Wrap-around map:** Voidd is now 30,000 units wide instead of 100,000, and it has no edges. Drive off one side and you come out on the other, with your drones and traps coming along with you.
- **Less lag:** there are now 8 of [THE DARKNESS] instead of 50, and the shapes have been scaled down to match the smaller map, so the density is the same as before. Voidd now uses a small fraction of the server time it did, which helps every gamemode on the same server.
