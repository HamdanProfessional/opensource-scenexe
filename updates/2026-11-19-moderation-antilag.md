**Open-Scenexe update: moderation tools and smarter lag protection**

You can now report players straight from the game, moderators have proper tools for spam and rule breakers, and a lag spike no longer wipes the whole server.

- **Report a player:** type /report followed by their name and what they did, like /report bob teaming. Moderators see it in game and on the Discord.
- **Mutes:** moderators can mute a player for a set time, like /mute bob 30m spamming. A mute stays even if the player leaves and comes back.
- **Timed bans:** bans can now have a length and a reason, like /ban bob 7d griefing. Banned players see the reason and how long is left.
- **Kick reasons:** when a moderator gives a reason for a kick, the player now sees it.
- **Moderator tools:** moderators can watch a player with /spectate, look someone up with /whois, and list bans and mutes. Staff on the Discord can do the same from there.
- **Smarter lag protection:** when the server lags, it now finds the dimension that caused it and clears only the bullets of the few tanks firing the most, and tells them. Bots and everyone else's bullets are only cleared if the lag keeps coming back, and other dimensions are never touched.
- **Smoother long sessions:** old announcements are now cleaned up properly instead of piling up in the background.
