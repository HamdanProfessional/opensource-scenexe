**Open-Scenexe update: Arras projectiles, security and a faster server**

Arras tanks now fire their special projectiles properly, the server is better protected against bots, and the busiest parts of the server now run in C.

- **Healer projectiles:** healer bullets, drones and minions now heal allied tanks, across 28 tanks.
- **Snake weaving:** projectiles in the Sidewinder line now weave as they fly, and snake missiles fire their thrusters the right way.
- **Satellites:** Whirlwind, Blizzard, Tornado and the other satellite tanks now have satellites that orbit around them.
- **Projectile limits:** tanks with a limit on their traps or bullets now respect it, and some replace their oldest one when full.
- **Stealth drones:** invisible drones fade out when still and show again when they move. Your own stay faintly visible.
- **Guns on projectiles:** more bullets and boomerangs now carry their own turrets and guns.
- **Security fixes:** several server security holes are closed, and passwords are now stored more safely. Yours is upgraded automatically the next time you log in.
- **Anti-bot:** stronger protection against bot floods, and too many wrong passwords now pause logins for a few minutes.
- **Faster server:** collision checks, visibility and network packets now run in compiled C code, which cuts the server's work per tick by about half in big fights.
